# Decision records

Short notes on why the design is what it is. `SPEC.md` describes the system;
these records explain how it got there.

Add one when a pull request changes `SPEC.md` in a meaningful way. Name it
`NNN-short-title.md` with the next number, and keep it to a page: context,
decision, alternatives considered. Records are not edited after merging; a
later record supersedes an earlier one and says so.
